# Sean Heffernan — preview

Static responsive site, hosted from main / root by GitHub Pages. No custom domain configured. All HTML uses noindex,follow during the preview. Music and awards feature verified links; no Pioneer Park promotion or release claims. The watch page embeds a published live session. Heartland Mile is a secondary feature.

## Before launch
- Download original artist photos into this repository (the preview uses Bandzoogle CDN URLs); create optimized WebP and a dedicated social-sharing image.
- Verify ownership of seanhef.com, connect domain with HTTPS, preserve /bio, /music and /shows by moving pages to clean directory URLs and adjust all relative links; plan redirects/aliases for any legacy URLs. Keep www redirect consistent.
- Update Open Graph URLs, WebSite and WebPage schema IDs and breadcrumbs to final HTTPS URLs; set self-referencing production canonical tags.
- Remove noindex from production pages only after domain switch; generate production sitemap.xml and robots.txt, verify in Search Console, submit sitemap and inspect URLs. Do not publish a preview sitemap.
- Verify booking email/contact form, mailing list, shows and release links; add GA4/GTM with relevant consent setup and conversion tracking.
- Test HTML, accessibility, live video playback, link integrity, Core Web Vitals and schema before launch. No ranking claims.
